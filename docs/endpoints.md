# Точки доступу

| № | Метод | Шлях | Сторінка або дія | Вхідні дані (з обмеженнями) | Вихідні дані | Коди помилок | Хто має право | Екран |
| :-: | :---: | :--- | :--- | :--- | :--- | :---: | :--- | :--- |
| **Т1** | GET | `/leagues` | `app/leagues/page.tsx` | — | 200, перелік ліг користувача | 401 | Увійшов у систему | Список ліг |
| **Т2** | POST | `/leagues` | `addLeagueAction` | `title` — обов'язкове, від 3 до 60 символів | 201, id створеної ліги | 400, 401, 403 | Організатор (акаунт А) | Список ліг |
| **Т3** | POST | `/leagues` | `deleteLeagueAction` | `id` — обов'язкове, валідний uuid | 200, повідомлення про успіх | 400, 401, 404 | Лише творець ліги (owner) | Список ліг |
| **Т4** | GET | `/leagues/[id]` | `app/leagues/[id]/page.tsx` | `id` — uuid ліги | 200, розклад матчів і турнірна таблиця | 401, 404 | Член відповідної ліги | Картка ліги |
| **Т5** | POST | `/leagues/[id]` | `submitPredictionAction` | `match_id` — uuid; `home_score` >= 0; `away_score` >= 0 | 201, id створеного прогнозу | 400, 401, 403 | Учасник ліги (до початку матчу) | Картка ліги |
| **Т6** | POST | `/leagues/[id]` | `updateScoreAction` | `match_id` — uuid; `home_score` >= 0; `away_score` >= 0 | 200, підтвердження фіксації | 400, 401, 403, 404 | Лише організатор ліги | Картка ліги |
| **Т7** | POST | `/leagues/[id]` | `submitComplaintAction` | `target_id` — uuid; `reason` — обов'язкове, 5–300 символів | 201, id скарги | 400, 401 | Будь-який учасник ліги | Картка ліги |
| **Т8** | GET | `/leagues/[id]/preview`| `app/leagues/[id]/preview/page.tsx` | `match_id` — uuid поєдинку | 200, текст аналітики ШІ | 401, 404 | Учасник ліги | ШІ-аналітика |
